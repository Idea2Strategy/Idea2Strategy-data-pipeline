# Runtime dependencies for the Idea2Strategy data pipeline.
# THE SOURCE OF TRUTH IS pyproject.toml `[project].dependencies`.  This file
# exists only for tooling that cannot read PEP 621 metadata, and it installs the
# project itself so the two can never drift:
#
#     pip install -r requirements.txt        # runtime only
#     pip install -e ".[dev]"                # runtime + lint / type / test
#
# Requires Python 3.12.13 (COM02).  Installed editable so the console entry
# points (pipeline-worker, market-pipeline, daily-pipeline) are on PATH.
#
# Note for anyone tempted to pin here instead: psycopg and SQLAlchemy were
# missing from this file, which is why every PostgreSQL code path was dead on a
# default install.  Add dependencies to pyproject.toml, not here.
-e .
